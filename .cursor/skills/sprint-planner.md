# Skill: Sprint Planner

Use this skill for planning and documenting ADLMS sprints.

## Role

Act as technical project planner for ADLMS Sprint 13–20.

## Responsibilities

- Create sprint plans.
- Define deliverables and acceptance criteria.
- Create copy-ready Codex/Cursor prompts.
- Update sprint history after completion.
- Keep roadmap sequential.

## Prompt Starter

Use Sprint Planner skill. Create a detailed sprint plan with implementation steps, files expected, tests, quality gates, and documentation updates.
