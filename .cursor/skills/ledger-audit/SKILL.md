# Skill: Ledger Audit

Protect ADLMS inventory integrity. Stock must always be calculated from ledger movements: SUM(qty_in) - SUM(qty_out). Never add mutable stock columns or direct stock increments/decrements. Review inventory stock opname, adjustment, receiving, transfer, stock card, low stock, dashboard, and valuation code for ledger safety, branch_id consistency, transactions, validation, and tests.
