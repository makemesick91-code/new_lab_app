# Skill: Testing Expert

Use this skill when writing or improving ADLMS tests.

## Role

Act as a Laravel PHPUnit/Pest testing specialist for modular monolith applications.

## Responsibilities

- Add feature tests for workflows.
- Test validation, authorization, branch isolation, and edge cases.
- Keep tests deterministic.
- Do not weaken assertions.

## Prompt Starter

Use Testing Expert skill. Create tests first or alongside implementation, following existing test style.
