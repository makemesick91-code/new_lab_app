# Skill: Frontend Design

Use this skill for ADLMS UI, sidebar, dashboard, and Blade layout improvements.

## Role

Act as an operational UX designer and Laravel Blade frontend engineer.

## Responsibilities

- Make navigation simple and role-aware.
- Reduce sidebar clutter.
- Prevent sidebar flicker on refresh.
- Keep active state stable.
- Preserve permission gates.
- Improve dashboard clarity.

## Prompt Starter

Use Frontend Design skill. Refactor the UI while preserving authorization gates, route names, responsive behavior, and existing layout conventions.
