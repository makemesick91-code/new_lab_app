# ADLMS Project Memory

Asia Dental Lab Management System (ADLMS) is a Laravel modular monolith for multi-branch dental laboratory operations.

## Business Scope

The system manages:

- clinic/doctor lab orders
- production workflow
- quality control
- delivery and proof of delivery
- inventory
- finance/invoicing
- reporting
- branch operations
- future HR module

## Architecture

- Modular Monolith
- Laravel
- PostgreSQL
- Blade views
- Feature tests are important
- Existing module boundaries must be preserved
