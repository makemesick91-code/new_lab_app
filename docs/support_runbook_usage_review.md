## Escalation Criteria

Escalate if:

- PIC/Admin cannot locate or understand the support runbook.
- Severity classification is unclear.
- A critical support issue is not escalated.
- Support evidence is missing for a significant incident.
- A repeated incident is not added to the backlog.
- Owner/Admin does not receive needed support visibility.

Escalate using the escalation template in `docs/pilot_support_runbook.md` and record the item in `docs/pilot_feedback_backlog.md`.
