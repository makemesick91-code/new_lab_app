# NSF-7 — Evidence Gate Automation R011/R012 to CI

## Objective

Automate NSF-R011 (full/critical regression tests) and NSF-R012 (build + Pint) as GitHub Actions evidence gates. Close NSF-M001/M002 deferred backlog items from FG-1.

## Baseline

- DQ-1/DQ-2/DQ-3/DQ-3.1: GO
- DMO-3: GO (`dmo-3-deferred-metric-backlog-closure-go`)
- FG-1 Combined Foundation: GO
- Prior NSF-R011/R012: `evidence_only` manual gates

## NSF-R011 — Full Suite Gate

| Tier | Job | Trigger |
| --- | --- | --- |
| PR gate | `critical_test_gate` | `pull_request` |
| Full gate | `full_suite_gate` | `push` to base, `schedule` (weekly), `workflow_dispatch` |

Commands: critical filter tests + governance audits; full `php artisan test` on full gate.

Artifact: `storage/ci-evidence/nsf-r011-critical-tests.txt`, `nsf-r011-full-suite.txt`

## NSF-R012 — Build Gate

| Job | Trigger |
| --- | --- |
| `quality_gate` | All workflow triggers |

Commands: `npm ci`, `npm run build`, `./vendor/bin/pint --test`, `git diff --check`

Artifact: `storage/ci-evidence/nsf-r012-build-pint.txt`

## Workflow

- Path: `.github/workflows/foundation-evidence-gates.yml`
- Name: Foundation Evidence Gates
- Base branch: `feature/sprint-26-phase-26-8-stabilization-closure-go-watch-no-go-report`
- Local script: `scripts/ci/foundation-evidence-gates.sh`

## Governance integration

- `config/foundation_governance.php` — `automated_ci_gate` for R011/R012
- `FoundationGovernanceSummaryService` — `ci_evidence_gates` JSON section
- No GitHub API token required for local governance summary
- Remote CI pass verified via `gh pr checks` / `gh run view` before GO tag

## Security

- No `.env`, DB dumps, PII, or secrets in artifacts
- CI does not deploy to VPS

## GO / WATCH / NO-GO

| Decision | Criteria |
| --- | --- |
| GO | Workflow exists; local governance passes; PR checks green |
| WATCH | Workflow missing or CI not yet run |
| NO-GO | Governance errors or failed required gate |

## Limitations

- Full suite not on every PR (performance)
- Browser/Dusk not in CI — future NSF item if needed
- GitHub run status not polled by Artisan commands

## Permanent rules

1. NSF-R011 evidence must be generated by CI (`critical_test_gate` minimum).
2. NSF-R012 evidence must be generated by CI (`quality_gate`).
3. CI artifacts must not include secrets, DB dumps, or PII.
4. Inspect GitHub Actions before GO tag.
5. Evidence-only manual status remains WATCH during bootstrap/outage.
6. Deploy gate includes DQ audits, DMO governance, NSF CI evidence, Foundation summary.
7. GO tag must not move for evidence-only doc commits.
