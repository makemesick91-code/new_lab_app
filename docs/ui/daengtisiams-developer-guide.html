DaengtisiaMS — Panduan Developer UI/UX

Panduan implementasi design system “luxury healthcare”. Refleksi in-repo dari file Claude Design (“DaengtisiaMS - Panduan Developer”). Token kanonik: tailwind.config.js + docs/ui/daengtisiams-design-tokens.md.

1. Konsep Visual

Bersih, mewah, ringan, cepat dibaca untuk klinik sibuk. Background putih/off-white, biru untuk aksi/focus/active/link/primary CTA, gold hanya aksen premium terbatas. Hindari UI gelap, ramai, terlalu warna-warni, atau berat.

3. Tipografi

Font: Figtree (sudah aktif). Skala: page title 24–28px/700, section 18–20px/600, body 14px, meta 12px uppercase tracking. Teks utama text-navy, sekunder text-ink-soft.

4. Spacing, Radius, Shadow

Radius kartu rounded-xl (12px), kontrol rounded-lg. Shadow lembut shadow-card. Padding kartu 20–24px. Density tabel: header 10–12px, sel 11px vertikal. Density form: input py-2, gap gap-4.

5. Komponen — pakai x-ui.*

{{-- Selalu pakai komponen, bukan class ad-hoc --}}
<x-ui.button variant="primary">Simpan</x-ui.button>
<x-ui.badge :status="$visit->status" />
<x-ui.kpi-card label="Pendapatan" value="Rp 128 jt" accent />
<x-ui.page-header title="Antrian Pasien">
    <x-slot:actions><x-ui.button>Tambah</x-ui.button></x-slot:actions>
</x-ui.page-header>
Jangan hardcode #hex di Blade. Jangan pakai gold sebagai primary CTA. Jangan duplikasi class komponen — extend komponen x-ui.*.

6. Pola Blade + Alpine

Alpine hanya untuk interaksi ringan (dropdown, modal open, tab). Tidak ada React/Vue. Tidak ada logika bisnis di Blade. State server tetap sumber kebenaran.

7. Responsive

Mobile-first. Sidebar collapse pada layar kecil (perilaku existing dipertahankan). Tabel lebar memakai overflow-x-auto. Body halaman tidak pernah horizontal-scroll.

8. State & Akses

Visibility UI mengikuti permission/Gate — sidebar bukan boundary keamanan. Setiap komponen mendukung default/hover/focus/disabled/loading dan varian error/warning/success/info bila relevan.

9. Tabel & Form

Tabel: header uppercase meta, baris hairline, badge status kanan/khusus kolom status. Form: label jelas, x-ui.input/select/textarea, pesan error merah di bawah field.

10. Print / PDF

View print/PDF (RME, odontogram, struk, receipt) tidak diubah oleh sprint fondasi. Layout struktural print harus dipertahankan; dompdf-safe (tanpa flexbox pada template PDF).

11. Aksesibilitas

Kontras teks minimum, focus ring biru terlihat, label untuk input, aria-* pada modal/alert, target sentuh ≥ 40px.

12. Performance

Tanpa library UI berat, tanpa animasi berat/aset besar. Hanya Tailwind + Alpine + Blade. Token via config, bukan CSS besar di app.css.

13. Strategi Migrasi & Prioritas

  1. Fondasi (sprint ini): token, shell, komponen, katalog, governance.
  2. UIX-2 Dashboard Owner, UIX-3 Kunjungan, UIX-4 RME/Odontogram, UIX-5 Kasir, UIX-6 Inventory, UIX-7 Lab, UIX-8 Reports/print.

Adopsi bertahap: jangan migrasi semua modul sekaligus. Reskin primitif bersama dulu (button/badge/card/table + active state sidebar).
