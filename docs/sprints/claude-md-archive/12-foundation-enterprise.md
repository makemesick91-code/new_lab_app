**Root cause (reproduced live, not inferred).** `GitChangeInspector::changedFiles()` diffed against a bare base **branch name**, which git resolves to the LOCAL `refs/heads/<branch>`. At sprint start the local base was `a3d1723` while the canonical remote was `b8038c5` — three commits behind. A stale/ahead/diverged local ref silently changed the scope audit, the manifest-vs-diff contradiction checks and the diff fed to security review, which is how earlier workstreams got a ~14.7 MB unrelated-checkout diff, a Graphify pre-state from another branch, and false "candidate regression" / "pre-existing failure" conclusions. Three paths, one defect class: **stale local**, **wrong checkout**, **base moving mid-run**.

**Canonical authority model (permanent).** `1. explicit verified exact SHA → 2. origin/<canonical-base> after fetch → 3. FAIL CLOSED.` There is **no** step 4: never `refs/heads/<base>`, `main`, `master`, `HEAD`, `HEAD~1`, or the latest tag. **Branch name = discovery authority; exact SHA = comparison authority.** A fetch/network/auth failure is an error, never a governance PASS over stale data.

**Delivered.** New `App\Support\Devflow\CanonicalBaseRefResolver` (the ONLY place a base is resolved) + immutable `CanonicalBaseRef` value object (pinned per invocation — a remote advancing mid-run cannot change that run; a new invocation may resolve a newer base). New `php artisan devflow:base-ref-check` (`--json`/`--strict`/`--base-sha`/`--base-branch`). New `config/devflow.php` `base_resolution` block (explicit `remote`, fetch toggle/timeout, `explicit_sha_env`, exact-SHA + safe-branch patterns, declared `forbidden_fallbacks`). `GitChangeInspector` consumes the resolver and returns `base_ref` metadata; **an unresolvable base surfaces as UNRESOLVED, never as an empty change set** (an empty set passes every contradiction check and silently fakes a GO). `ResolvesSprintContext` resolves once per command and exposes `--base-sha`/`--base-branch` + `reportBaseAuthority()`; `sprint:manifest-check` and `sprint:scope-audit` **fail closed (NO-GO)** on an unresolved base and print `BASE_SOURCE`/`BASE_BRANCH`/`BASE_SHA`/`HEAD_SHA`(+`MERGE_BASE_SHA`/`LOCAL_BASE_STALE`). `scripts/ci/resolve-gates.sh` gains `--base-sha`, validates refs, pins an exact commit before diffing, and publishes `base_source`/`base_sha`/`head_sha` in kv + JSON + stderr summary. CI `classify` now uses the **immutable** `github.event.pull_request.base.sha` instead of the moving `origin/${{ github.base_ref }}`, publishes the authority as job outputs + step summary. `DevflowScanner::baseResolutionPosture()` + `DEVFLOW-BASE-AUTHORITY` governance check; rules **DEVFLOW-R011..R020**.

**Two pre-existing fail-opens found by RUNNING the new tooling (fixed here — same function).** (a) `lines()` trimmed each `git status --porcelain` line **before** `substr($line, 3)`, so every MODIFIED tracked path shifted left one char (`app/Policies/X.php` → `pp/Policies/X.php`, `database/migrations/…` → `atabase/migrations/…`) and stopped matching the `security_impact`/`schema_change` contradiction patterns. (b) Default porcelain collapses untracked files in a brand-new directory to `newdir/`, so a new module folder of `.js` or migration files could never match an extension/filename pattern. Now parsed with `-z -uall` + `core.quotePath=false`, sliced at the exact offset, both sides of a rename recorded.

Option injection at that call site is blocked by **validation**, not by `--`. `git diff` *does* take a trailing `--`.
