# Sprint Documentation Writer

Update only the relevant sprint section.

Format:
- Sprint name
- Status
- Files changed
- Features completed
- Tests/quality gates
- Risks/future improvements
- Commit/tag if applicable

Do not rewrite the entire document.
Do not change old sprint history except to add a new entry.
