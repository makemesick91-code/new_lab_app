# ADLMS Cursor Package

Copy the `.cursor` folder into your Laravel project root:

```text
D:\new_lab_app\.cursor
```

Final structure:

```text
D:\new_lab_app
└── .cursor
    ├── rules
    ├── memory
    └── skills
```

After copying, reload Cursor:

```text
Ctrl + Shift + P → Developer: Reload Window
```

Test in Cursor Chat:

```text
Read .cursor/rules and summarize the ADLMS rules you will follow.
```
